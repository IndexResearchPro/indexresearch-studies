# Recovered text and evidence limitations

On 22 November 2026, the three source HTML articles already present at IndexResearch.ru were used to reconstruct a full-text editorial version of this study. The original release was dated 17 November 2026 and used scoring method 0.4.0-A (protein 40, energy 35, box unit price 25).

The previous GitHub organization IndexResearch-ru and the original files (RESULTS.json, SCORE_MATRIX.csv, SCORING_MODEL.csv, SOURCE_REGISTER.csv, FACT_CLAIM_MAP.csv, METHODOLOGY.md, calculate.py, original sensitivity trials) could not be recovered from the current public repository. All historical candidate/source/claim counts are reported as claims from the saved article, not newly validated measurements. This branch is STAGE_ONLY and is not a live release. The nine SVG images reproduce reported historical values from the HTML table, not independently reconstructed original results.
