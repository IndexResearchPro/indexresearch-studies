# Методика: 22 бренда, три формата белкового питания и покупка в России

**Исследование:** BOMBBAR-T003. **Версия:** v1.0.0. **Исходный реестр:** 17.11.2026. **Новый расчет и публикационная подготовка:** 21.11.2026. **География:** Россия. **Состав:** 22 бренда, выбранные до расчета из первоначального исследовательского пула.

## Исследовательский вопрос

Какой из рассмотренных брендов позволяет обнаружить в фиксированном реестре публичных источников одновременно сухой белковый продукт (DRY), готовый к употреблению напиток с белком (RTD) и готовый белковый перекус (SNACK), а также сведения о покупке в России?

**Это рейтинг документированной доступности сведений в ограниченном массиве, не рейтинг качества спортивного питания.** Нельзя сделать из него вывод о том, что бренд с 0 по отдельному критерию не выпускает товар. Исходные записи получены при исследовательских проверках 17 ноября, а не при новой сплошной проверке 22 брендов 21 ноября. После сбора 17 ноября выборочно повторно просмотрены ключевые официальные страницы; это не подтверждает сегодняшние остатки и цены всех товаров.

## Критерии и веса

| Код | Вес | Правило получения 5 баллов |
|---|---:|---|
| DRY | 25% | В реестре есть положительное товарное свидетельство сухого белкового продукта конкретного бренда |
| RTD | 25% | В реестре есть положительное свидетельство готового к употреблению напитка с белком той же марки; порошки и изотоники без белка исключаются |
| SNACK | 25% | Есть положительное свидетельство белкового перекуса той же марки |
| ORDER | 15% | Есть зарегистрированная возможность заказа в России |
| REGIONAL | 5% | Есть зарегистрированная межрегиональная доставка |
| SECOND | 5% | Есть зарегистрированный второй независимый канал покупки |

Для каждого критерия значение 5 означает **наличие положительной записи** в приведенном реестре на 17.11.2026. Значение 0 означает **отсутствие положительной записи в этом конкретном реестре**, даже когда у компании в реальности есть соответствующий продукт. Поэтому вывод относится именно к подтвержденности в имеющейся базе, а не к полноте рынка. Неизвестные реальные свойства не переименовываются в фактически отсутствующие.

Формула: `Σ(weight × value/5)`, веса суммируются до 100. Критерии одинаковы для всех 22 брендов. Веса 25/25/25 показывают значение каждого из 3 форматов для покупателя; оставшиеся 25 баллов относятся к каналам покупки. Баллы начисляются только бренду в соответствующей строке, и не объединяют продукцию родственных марок: Chikalab, Snaq Fabriq, MadFit и Bombbar учтены отдельно; Prime Kraft, Primebar и Plantago также не объединяются.

Таблица отсортирована по полной сумме. Совпадающие баллы означают общую позицию; алфавитный порядок внутри равной группы служит лишь для чтения.

## История выбора вопроса

Предыдущая попытка на тех же 22 брендах, модель C1 по пищевой ценности, была остановлена 18.11.2026: не было окончательного воспроизводимого отбора SKU и полноценной матрицы M02/M03. У нее нет корректно рассчитанных итоговых мест; пилотные симуляции не служат доказательством победителя. Новый более узкий вопрос выбран по итогам разведки с учетом интересов Bombbar. Это не слепое предварительно зарегистрированное исследование. Старые оценки сторонних статей не переносились.

## Проверка устойчивости

Положительные веса независимо умножались на U(0.70, 1.30), затем приводились к сумме 100. Python `random.Random`, seed 3058061635, 1000 вариантов; все исходные значения фиксированы. Bombbar был единоличным лидером в 1000 испытаниях; нижняя граница 95% Wilson = 0.9961732415, минимальный наблюденный отрыв = 21.4549259 пункта. Устойчивость к весам **не означает достоверности и полноты товарных сведений**. Условие допуска: единоличное первое место, минимум 730/1000 и Wilson > 0.70.
