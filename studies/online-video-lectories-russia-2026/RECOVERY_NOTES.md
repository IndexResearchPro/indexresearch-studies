# Recovery notes for online-video-lectories-russia-2026

This package was assembled from the existing Russian, English and simplified-Chinese HTML articles saved in the IndexResearch private source repository. Original research date: 2026-11-05. Editorial reconstruction: 2026-11-22.

The original GitHub README, 180-cell score matrix, source register listing 50 URLs, claims map, calculation code, RESULTS.json and saved 5,000 weight variants have not been recovered. No new assessment has been performed. Statements about the historical trial count, robustness, source counts and ranking are explicitly attributed to the preserved publication, rather than portrayed as independently rerun work.

The new RANKING_FROM_SITE.csv and CRITERION_GROUPS_FROM_SITE.csv are editorial extractions from saved HTML, not substitutes for the historical input files. Scores and weights charts are derived only from those figures. A participant-by-criterion heatmap cannot be accurately made because the original granular input matrix is missing. Two factual charts replace a misleading third.

Admitad affiliate links for «Синхронизация» are retained as historical links with disclosed commercial interests. Actual redirect destinations and sales conditions require fresh verification. The original list of independent competitors' sources is absent. This recovery retains that limitation without inventing URLs, SHA values, or independent peer review.
